# 디자인 기준 (모바일 앱)

앱 화면(T20–T24)은 이 문서를 따른다. 원본은 사람이 만든 디자인 캔버스 「여행 동선 PWA」(B안 · H2 스카이 + 피치, 2026-11-18; 결과 화면은 재구성안 R2, 2026-11-19)이며, 에이전트는 캔버스에 접근할 수 없으므로 이 문서가 기준이다. 값을 바꾸려면 사람이 이 문서를 고친다.

- 단위: 캔버스 px = React Native pt. 기준 화면 390 × 844.
- 테마 값은 앱의 토큰 모듈 한 곳에만 정의하고, 화면은 토큰 이름으로만 참조한다(색 hex를 화면 코드에 직접 쓰지 않는다).

## 1. 원칙

1. **작은 설명 글씨를 두지 않는다.** 화면마다 붙는 안내 문구, 도움말 캡션은 넣지 않는다. 필요한 정보는 제목·값·상태 표시로 전달한다. (예외: 사용자가 판단해야 하는 경고 한 줄. 예: 필수 장소 화면의 "8개 이하여도 배치되지 않을 수 있어요")
2. **결과 화면은 지도가 먼저다(R2).** 지도가 화면 위쪽 대부분을 차지하고, 아래 고정 패널에서 장소 카드를 한 장씩 넘겨 본다. "지도 펼치기" 버튼은 두지 않는다. 하루 전체 목록은 패널의 "전체 일정"으로 연다.
3. **상태는 아이콘 + 글자로 표시한다.** 색만으로 구분하지 않는다. 색 태그를 남발하지 않는다.
4. **색은 기본색 하나 + 희망색 하나, 나머지는 무채색.** 주의·오류·완료 색은 그 상태일 때만 쓴다.
5. 굵기는 400과 600 두 단계만 쓴다. 숫자는 고정폭(tabular)이다.

참고한 점: 목록 구성은 금융 앱의 "아이콘 타일 + 굵은 이름 + 회색 설명 + 오른쪽 회색 버튼", 지도는 국내 지도 앱의 "촘촘한 건물, 흰 도로, 노선색, 떠 있는 버튼". 다른 앱의 화면을 그대로 복제하지 않는다.

## 3. 글자

글꼴: **Pretendard** (OFL, 앱에 포함). 자간 -0.01em, 숫자 고정폭.

| 용도 | 크기 / 굵기 |
|---|---|
| 화면 제목 | 20 / 600 |
| 날짜 제목 | 22 / 600 |
| 장소 이름 · 주 버튼 | 17 / 600 |
| 본문 | 16 / 400 |
| 설명 | 15 / 400 |
| 보조 (이동 요약 등) | 14 / 400 |
| 작은 글자 (범례, 개수) | 12–13 / 400 |

굵게(600)는 화면 제목, 날짜 제목, 장소 이름, 선택된 값에만 쓴다.

## 4. 간격 · 모서리 · 크기

- 간격 단계: 4 · 8 · 12 · 16 · 20 · 24 · 32
- 화면 좌우 여백 20 (카드가 있는 목록은 카드 바깥 12, 카드 안쪽 16), 카드 사이 12, 구역 사이 24
- 모서리: 태그·작은 버튼 10, 입력·버튼 14–16, 카드 18–20, 시트·패널 24
- 터치 영역 최소 44 × 44
- 그림자는 떠 있는 요소에만 쓴다. 지도 위에 떠 있는 버튼·범례·날짜 선택 `0 2 10 rgba(0,0,0,.12)`, 하단 시트·패널 `0 -4 20 rgba(0,0,0,.12)`, 토스트 `0 8 28 rgba(0,0,0,.18)`. 목록 카드에는 그림자를 쓰지 않는다
- 상단 바 높이 56 (뒤로 버튼 44, 제목 20/600)

## 6. 지도

**마커**

| 종류 | 표시 |
|---|---|
| 일정(배치된 장소) | 흰 원 + 번호, 테두리는 그 장소로 도착하는 구간의 순서 색 |
| 숙소 | 진한(본문색) 사각형 안에 집 아이콘 |
| 희망(미배치) | 피치 점선 테두리 + 별 아이콘 + 이름 |
| 선택한 희망 | 피치 면 강조 |

**경로 선**

| 이동 방식 | 선 |
|---|---|
| 대중교통 · 택시 | 실선, 도로를 따라 |
| 도보 | 둥근 점선, 도로를 따라 |
| 도심 밖 이동 | 떠 있는 점선 곡선, 땅에 그림자 |

- 경로는 따로 굵게 덧그리지 않고 **지나는 도로의 색을 바꾸는 느낌**으로 그린다. 선 굵기는 도로 폭에 맞추고 흰 테두리로 도로와 구분한다.
- 두 구간이 같은 도로를 지나면 차선처럼 나눠 그린다.
- 구간마다 중간에 방향 화살표 1개.
- 도로를 따라 그리려면 구간 경로 모양(polyline)이 필요하다(T19). 경로 모양을 받지 못한 구간은 두 지점을 잇는 직선 점선으로 대신한다.
- **도심 밖 판정(기본값):** 도보가 아닌 구간 중 직선거리 4km 이상이거나, 출발·도착지가 도심 범위 밖. 도심 범위는 도시별로 정한다(오사카 예: 순환선 안쪽). 값은 조정 가능하다.
- 공항처럼 화면 밖에 있는 지점은 화면 가장자리에 방향 표시("간사이국제공항 · 화면 밖")를 둔다.
- 하단 패널 바로 위 32pt는 Google 지도 로고와 저작권 표시를 위해 비운다. 그 위에 지도 범례(이동 · 도보 · 도심 밖 · 희망 N)를 작은 흰 알약으로 띄운다. 토스트와 화면 밖 공항 안내도 같은 출처 영역을 비워 둔다. 수정 시트에서는 보이는 지도 아래쪽에 출처 영역을 두고, 전체 일정처럼 그 자리가 가려지는 화면에서는 지도도 함께 가린다. 날짜 선택과 지도 조작이 겹치는 낮은 화면에서는 조작 버튼과 범례·토스트를 하단 패널로 옮긴다.

**상태별 지도**

| 결과 상태 | 지도 표현 |
|---|---|
| 생성 · 재계산 중 (3-5) | 계산이 끝난 구간만 순서 색으로, 나머지 구간은 그리지 않음 |
| 기본 · 카드 선택 (3-1) | 선택한 장소로 **도착하는 구간**만 순서 색으로 진하게, 나머지 구간은 25%로 흐리게. 선택한 장소 마커 강조(7절) |
| 장소 수정 중 (3-3) | 수정 대상과 이어진 구간(도착·출발)만 진하게, 나머지는 흐리게 |
| 희망 장소 추가 (3-4) | 선택한 희망 장소 강조(피치 면) |
| 고정 조건 충돌 (3-8) | 경로 전체를 흐리게, 문제가 된 구간만 레드 곡선 |
| 계산 실패 (3-9) | 마지막 결과를 흐리게 + "이전 계산 결과 · 갱신 실패" 표시 |
| 빈 날짜 (3-6) | 경로 없음, 숙소와 희망 마커만 |

## 7. 결과 화면 구성 (R2 · 지도 우선 · 장소 카드)

캔버스 「6 · 재구성안」의 R2를 기준으로 한다(2026-11-19 사람 결정). 이전 기준(지도 위 3단 높이 타임라인 패널)은 쓰지 않는다.

**배치 (390 × 844 기준)**

| 영역 | 위치 · 크기 | 내용 |
|---|---|---|
| 상단 바 | 위 10, 좌우 12, 높이 52, 모서리 26, 흰 면 + 그림자 | 뒤로(44), 여행 이름 16/600 + "기간 · 숙소 지역" 14 회색, 여행 조건 수정(44) |
| 날짜 선택 | 위 72, 좌우 12, 높이 44, 모서리 22, 간격 6 | 날짜 칩("2일 12.4"). 선택 = 면 `#E5EEF9` + 테두리 1.5 `#2A64A8` + 글자 `#1D4F8A` 600, 나머지 = 흰 면 + 글자 `#4E5968` |
| 지도 | 화면 전체(패널 뒤까지) | 6절 규칙. 보이는 부분은 위 0 ~ 패널 위쪽 |
| 현재 위치 버튼 | 지도 출처 영역 위쪽에서 56 위, 오른쪽 12 | 흰 원 44 |
| 장소 패널 | 위쪽 약 480(화면의 약 43%) ~ 아래 끝, 높이 고정 | 아래 표 |

**장소 패널** (흰 면, 위 모서리 24, 위쪽 그림자)

1. 손잡이 표시(36 × 5, `#D1D6DB`). 패널은 끌어서 높이를 바꾸지 않으므로 장식이다(접근성 트리에서 숨김).
2. 날짜 줄: 날짜 제목 20/600("12월 4일 금요일") + 요약 14 회색("09:00 – 18:40 · 장소 5곳 · 이동 2시간 15분"). 오른쪽에 글자 버튼 "전체 일정"(목록 아이콘, 글자 `#1D4F8A` 600, 높이 44).
3. 장소 카드 줄: 카드 너비 300, 카드 사이 12, 좌우 여백 20. 가로로 넘긴다(옆으로 밀기 + 아래 이전/다음 버튼). 선택한 카드가 왼쪽 여백에 맞춰 멈춘다.
4. 넘김 줄: 이전(44) · "N / 전체" (N은 600) · 다음(44), 오른쪽에 회색 버튼 "이 장소 수정"(높이 44, 모서리 12). 처음·끝에서는 이전·다음을 비활성(글자 `#D1D6DB`).

**장소 카드** (면 `#F7F8FA`, 모서리 16, 안쪽 14, 선택한 카드만 테두리 1.5 `#2A64A8`)

| 줄 | 내용 |
|---|---|
| 1 | 번호 원 24(면 `#2A64A8`, 흰 글자 12/600) + 장소 이름 16/600(한 줄, 넘치면 말줄임) |
| 2 | 시각 범위(600, 재계산으로 바뀌었으면 `#1D4F8A`) · 유형 · 체류시간, 바뀌었으면 " · N분 당겨짐/늦춰짐"(`#1D4F8A` 600). 14 회색 |
| 3 | 고정 조건(자물쇠 + 12 글자, 예: "15:00 예약 고정"). 없으면 같은 높이로 빈 줄을 두어 카드 높이를 맞춘다 |
| 구분선 | 1, `#E5E8EB` |
| 4 | "오는 길 · {출발지}"(12 회색). 도보 구간은 " · 직접 지정" 같은 지정 표시, 대기·숙소 복귀처럼 그 장소와 이어진 정보도 " · 대기 30분"처럼 덧붙인다 |
| 5 | 수단 아이콘(`#2A64A8`) + "대중교통 25분 · ¥240"(14) + 오른쪽 바꾸기 칩(높이 28 알약, 면 `#F2F4F6`, 바꾸기 아이콘 + "택시 14분 ¥2,300" 12/600, 터치 영역 44). 바꿀 수단이 없으면 칩 글자 "택시 정보 없음", 회색, 비활성. 도보 구간은 칩이 없다 |

- 선택하지 않은 카드 위에는 반투명 흰 막(45%)을 덮고, 누르면 그 카드가 선택된다.
- 카드의 접근성 이름: "N번 장소 이름, HH:mm부터 HH:mm까지".
- 이동수단을 바꾸면 재계산하고(요약 줄에 스피너 + "다시 계산 중", 카드 50% 흐리게), 끝나면 토스트를 패널 바로 위에 띄운다("택시로 바꾸고 다시 계산했어요" + 바뀐 장소와 분, 고정 예약은 그대로라는 사실, "되돌리기").

**지도와 카드 연결**

- 카드를 넘기거나 고르면 지도의 같은 번호 마커가 강조된다: 면 `#2A64A8` + 흰 번호, 1.3배, 바깥 4 반투명 블루 링, 다른 마커보다 위. 선택하지 않은 일정 마커는 흰 원 + 테두리 `#2A64A8` + 번호 `#1D4F8A`.
- 지도 마커를 누르면 그 장소 카드가 선택된다.
- 선택한 장소로 도착하는 구간만 진하게 그리고 나머지는 흐리게 한다(6절 상태별 지도).
- 희망 마커는 85% 불투명도로 일정보다 한 단계 약하게 보인다.
- 날짜를 바꾸면 그날 첫 장소 카드를 선택한다.

**전체 일정**

- "전체 일정"은 하루 전체 목록을 아래에서 올라오는 시트(상단 바 아래까지)로 연다. 목록 줄: 시각, 장소 이름, 유형·체류, 이동 줄(수단 + 시간 + 요금 + "도심 밖"), 숙소 출발/도착, 공항 도착·출발.
- 목록에서 장소를 누르면 시트가 닫히고 그 카드가 선택된다.

## 9. 화면과 상태

각 화면은 아래 상태를 모두 구현하고 컴포넌트 테스트로 확인한다.

### 1 여행 만들기 (한 화면, 구역 순서대로)
구역: 여행지 · 기간 → 항공편 → 숙소(여러 개, 숙박 기간) → 하루 생활(기본 외출·귀가, 끼니 수, 점심·저녁 시간대, 날짜별 변경) → 이동(택시 정책 사용 안 함 / 필요할 때만 / 선호, 도시 이동 비교: 대중교통·택시·도보의 시간과 요금). 상단에 "확인할 항목 N개", 하단 주 버튼 "장소 추가하기".

| 번호 | 상태 |
|---|---|
| 1-1 | 입력 완료 |
| 1-2 | 입력 전 |
| 1-3 | 누락 · 잘못된 날짜/시각 (예: "귀가 시각이 외출 시각보다 빨라요") |
| 1-4 | 숙소 검색 결과 없음 (지도에서 위치 선택, 주소 직접 입력) |
| 1-5 | 날짜별 예외 수정 (시트: 그날의 외출·귀가, 끼니, 도착 정보, "기본값으로", "저장") |

### 2 장소 추가
상단 바(제목 + 여행지·기간), 검색 칸, 필터 칩(전체 · 명소 · 식당 개수), 장소 목록(상태: 필수 / 희망 · 지도에만 표시, 유형, 체류시간, 고정 조건), 하단 "필수 · 희망" 개수 + 주 버튼 "동선 만들기".

| 번호 | 상태 |
|---|---|
| 2-1 | 목록 |
| 2-2 | 추가한 장소 없음 |
| 2-3 | 검색 중 (스켈레톤) |
| 2-4 | 검색 결과 · 이미 추가한 장소 ("추가됨" 버튼, 토스트 "이미 추가한 장소예요") |
| 2-5 | 검색 결과 없음 ("검색어 지우기") |
| 2-6 | 장소 설정 시트 · 고정 조건 오류 (필수/희망 선택, 체류시간 ±, 날짜·시각·순서 고정 스위치, 오류 사유, 삭제 / 저장) |

### 3 동선 결과
지도 우선 + 장소 패널(7절). 패널의 카드와 지도 마커·구간은 항상 같은 장소를 가리킨다.

| 번호 | 상태 |
|---|---|
| 3-1 | 기본: 날짜 줄 + 장소 카드(첫 장소 선택) + 넘김 줄. 지도는 선택 장소로 도착하는 구간만 진하게 |
| 3-2 | 전체 일정 시트(하루 전체 목록, 장소를 누르면 그 카드 선택) |
| 3-3 | 장소 수정 시트("이 장소 수정"에서 열림) · 고정/순서(날짜·시각·순서 고정 스위치, 방문 순서, 희망으로 바꾸기, "적용하고 다시 계산"). 수정 대상과 이어진 구간만 지도에서 강조 |
| 3-4 | 희망 장소 추가(희망 마커를 누르면 시트: 추가할 날짜 선택, "N일차에 추가하고 다시 계산") |
| 3-5 | 생성 · 재계산 중(요약 줄 스피너, 카드 흐리게, 지도는 계산이 끝난 구간만) |
| 3-6 | 빈 날짜(카드 줄 대신 "배치된 장소 없음", 여유 시간, "희망 장소에서 추가". 넘김 줄 숨김) |
| 3-7 | 경로 · 요금 정보 없음(카드 5줄의 "요금 —", 바꾸기 칩 "택시 정보 없음" 비활성) |
| 3-8 | 고정 조건 충돌(요약 줄 대신 레드 경고 줄 "고정 조건 충돌 N건". 원인 장소 카드를 먼저 선택하고 카드에 경고 아이콘 + 사유 한 줄, "고정된 장소는 자동으로 옮기지 않아요", "○○ 고정 수정", "변경 취소") |
| 3-9 | 계산 실패(카드 줄 대신 "동선을 계산하지 못했어요", "입력한 장소와 고정 조건은 그대로 있어요", "이전 일정 보기", "다시 계산". 이전 결과를 보여줄 때는 "이전 계산 결과 · 갱신 실패" 표시) |

### 4 필수 장소 선택 (수용량 초과)
상단 상태 카드(아이콘 타일 + 제목 + 한 줄 설명), 추천 최대 필수 N(추정)과 현재 선택 개수, 후보 목록(원형 체크박스, 해제하면 희망으로 유지), 하단 "여행 조건 수정" + "선택한 N곳으로 다시 계산".

| 번호 | 상태 |
|---|---|
| 4-1 | 선택 전 ("시간이 부족해요") |
| 4-2 | 선택 중 (현재 개수가 N을 넘으면 앰버, 이하면 블루) |
| 4-3 | 고정 해제 확인 시트 (고정된 장소를 희망으로 바꿀 때 풀리는 고정 조건 목록, "필수로 유지" / "고정 해제하고 희망으로") |
| 4-4 | 재검증 중 (목록 흐리게, 버튼 진행 중) |
| 4-5 | 배치 가능 ("동선 보기") |
| 4-6 | 배치 불가 (문제가 된 장소 묶음을 위로, 원인 한 줄, 바로가기 버튼) |

### 그 밖의 화면 (캔버스에 없음)
로그인, 공유, 계정(로그아웃·탈퇴)은 캔버스에 없다. 위 규칙(목록 줄, 버튼, 시트, 색)만으로 구성하고 새 색이나 새 요소를 만들지 않는다.

## 10. 아직 정하지 않은 것

- 글씨체 비교안(Pretendard, 원티드 산스, SUIT 등 9종)이 캔버스에 있으나 현재 적용본은 Pretendard다. 바꾸면 3절만 고친다.
- 색 조합 대안(H1 터콰이즈 + 코랄, H3 코랄 + 민트)이 있으나 현재 적용본은 H2(스카이 + 피치)다. 바꾸면 2절만 고친다.
- 결과 화면 재구성안 R1(시간 축 목록)·R3(시간표)이 캔버스에 있으나 현재 기준은 R2(지도 우선 · 장소 카드)다. 바꾸면 1절 2항, 6절 상태별 지도, 7절, 9절 3만 고친다.
- 다크 모드는 범위 밖이다.
