# 디자인 규칙

화면을 만들거나 고칠 때 따르는 시각 규칙이다. 원본 시안은 Design 캔버스에 있다.

- 캔버스: https://claude.ai/artifact/NCS9JGsitQz1PSSq3gWdu4 (소유자 비공개. 열람하려면 소유자가 공유해야 한다)
  - `2 · 디자인 규칙` 페이지: 이 문서의 원본(색·글자·간격·구성 요소·지도 경로 표현)
  - `3 · 핵심 화면` 페이지: 여행 만들기 · 장소 추가 · 동선 결과 · 필수 장소 선택과 상태별 화면
- 토큰 값은 `src/app/globals.css`의 `:root` 변수 한 곳에만 둔다. 컴포넌트 CSS는 변수를 쓰고 색 값을 직접 쓰지 않는다.
- 기준 폭은 휴대폰 390px(최소 375px)이다.

## 1. 참고한 점

| 참고 | 가져온 규칙 |
|---|---|
| 토스 | 한 줄 = 40–44px 아이콘 타일 + 굵은 값 + 회색 설명 + 오른쪽 회색 버튼. 굵게는 화면 제목·날짜 제목·장소 이름·선택된 값에만 쓴다. 색 태그 대신 아이콘 + 회색 글자로 상태를 표시한다 |
| 네이버 지도 | 촘촘한 건물·흰 도로·노선색·떠 있는 버튼. 경로는 따로 굵게 그리지 않고 지나는 도로의 폭에 맞춰 색을 바꾼다 |
| 색 조합(H2) | 기본색 하나(스카이 블루)와 희망 장소 색 하나(피치), 나머지는 무채색. 주의·오류·완료 색은 그 상태일 때만 쓴다 |

## 2. 토큰

### 색

| 변수 | 값 | 용도 |
|---|---|---|
| `--color-primary` | `#2A64A8` | 주 버튼, 선택 상태, 일정 번호 |
| `--color-primary-strong` | `#1D4F8A` | 연한 면 위 글자 |
| `--color-primary-soft` | `#E5EEF9` | 선택된 칩·타일 면 |
| `--color-wish` / `-text` / `-soft` | `#E2804F` / `#A8501E` / `#FDEEE4` | 희망 장소(지도 점선 마커, 별 아이콘) |
| `--color-warning` / `-soft` | `#8A5A00` / `#FFF4D6` | 시간 부족 |
| `--color-success` / `-soft` | `#2F6B12` / `#E3F6D5` | 배치 가능 |
| `--color-danger` / `-soft` | `#D92D20` / `#FEECEA` | 오류·충돌 |
| `--color-ink` / `-2` / `-3` | `#191F28` / `#4E5968` / `#6B7684` | 본문 / 보조 / 설명 |
| `--color-line` / `-strong` | `#F0F1F3` / `#D1D6DB` | 구분선 / 꺼진 스위치·손잡이 |
| `--color-fill` | `#F2F4F6` | 회색 버튼, 입력칸, 타일 면 |
| `--leg-1` … `--leg-6` | `#5B9BE0` → `#B866A6` | 지도 경로 구간 순서 색(하늘색 → 보라·분홍) |

글자 대비는 4.5:1 이상을 지킨다. 파스텔 면 위의 글자는 같은 계열의 진한 색을 쓴다.

### 글자

- 글꼴: Pretendard Variable(`pretendard` 패키지, 자체 호스팅, SIL OFL 1.1).
- 굵기는 두 단계만: 400(`--weight-regular`), 600(`--weight-strong`).
- 크기: 날짜 제목 22 · 화면 제목 24 · 장소 이름 17 · 본문 16 · 설명 15 · 보조 14 · 작은 글자 12. 숫자는 고정폭(`tabular-nums`).

### 간격·모서리·그림자

- 화면 여백 20, 카드 사이 12, 카드 안쪽 20, 줄 위아래 12–14.
- 모서리: 작은 칸 10 · 입력·버튼 14 · 카드 20 · 시트·패널 24.
- 지도 위에 떠 있는 요소만 그림자(`--shadow-float`), 아래 시트는 `--shadow-sheet`.

## 3. 구성 요소

- **버튼:** 주 버튼은 기본색 채움(높이 48–56). 보조 버튼은 회색 면 + 보조 글자. 비활성은 회색.
- **입력:** 회색 면(`--color-fill`) 높이 52, 테두리 없음. 포커스는 기본색 안쪽 1.5px 선, 오류는 빨간 면 + 빨간 안쪽 선 + 바로 아래 오류 문구.
- **줄:** 타일(40–44) + 값(17/600) + 설명(14–15, `--color-ink-3`) + 오른쪽 회색 버튼(높이 36, `수정`·`설정`·`변경`).
- **상태 표시:** 고정은 자물쇠 아이콘 + 회색 글자(`15:00 예약 고정`). 필수는 체크 아이콘 + 기본색 글자, 희망은 별 아이콘 + 피치 글자(`희망 · 지도에만 표시`). 색만으로 구분하지 않는다.
- **점선:** 지도 위(경로·희망 마커·지도 범례)에서만 쓴다. 목록·버튼·시트는 실선과 면만 쓴다.
- **움직임:** 화면 전환 280ms, 패널 스냅 320ms `cubic-bezier(.22, 1, .36, 1)`, 시트 260ms. 동작 줄이기 설정을 따른다.

## 4. 동선 결과의 지도·패널

- 지도 위에 타임라인 패널을 겹친다. 기본은 타임라인이 화면의 약 60%, 손잡이를 끌어 내리면 지도 중심(요약 줄만), 끌어 올리면 목록 전체.
- 끄는 영역은 손잡이와 날짜 요약, 구분선 아래는 목록 스크롤. 손잡이를 탭해도 높이가 바뀐다(접근성 대체 동작).
- 날짜 선택은 지도 위 상단에 떠 있는 버튼으로 두어 패널 높이와 무관하게 유지한다.
- 경로: 구간마다 순서 색, 흰 테두리, 구간 중간에 방향 화살표 1개. 같은 도로를 두 구간이 지나면 차선처럼 나눈다.
  - 대중교통·택시: 실선 / 도보: 둥근 점선 / 도심 밖 이동: 땅 그림자가 있는 떠 있는 점선 곡선.
  - 도심 밖 판정(기본값): 도보가 아닌 구간 중 직선거리 4km 이상이거나 출발·도착지가 도심 범위 밖. 도심 범위는 여행지별로 정한다.
- 마커: 일정 장소는 흰 원 + 도착 구간 색 테두리 + 번호, 숙소는 진한 사각형, 희망 장소는 피치 점선 + 별 아이콘.
- 상태별 지도: 계산 중은 계산된 구간만 색으로, 충돌은 문제 구간만 빨간 곡선, 실패는 마지막 결과를 흐리게 + `이전 계산 결과` 표시.

## 5. 화면과 작업 대응

| 캔버스 화면 | 앱 경로 | 작업 |
|---|---|---|
| 공통 규칙 | `src/app/globals.css` | T16 |
| 1 여행 만들기 | `/trips/new`(여행·항공·숙소), `/trips/[id]/settings`(하루 생활·이동) | T17 |
| 2 장소 추가 | `/trips/new`의 장소 단계, `place-picker` | T18 |
| 3 동선 결과 | `/trips/[id]/result`, `/share/[token]` | T19 |
| 4 필수 장소 선택 | `/trips/[id]/result`의 수용량 초과 상태 | T20 |

앱의 입력 흐름(단계형 입력 → 생활 설정 페이지)은 유지하고 각 화면의 시각 구성만 캔버스를 따른다. 근거와 남은 결정은 [T16 결정](decisions/T16-design-system.md).
