# 디자인 기준 (모바일 앱)

앱 화면(T20–T24)은 이 문서를 따른다. 원본은 사람이 만든 디자인 캔버스 「여행 동선 PWA」(B안 · H2 스카이 + 피치, 2026-11-18)이며, 에이전트는 캔버스에 접근할 수 없으므로 이 문서가 기준이다. 값을 바꾸려면 사람이 이 문서를 고친다.

- 단위: 캔버스 px = React Native pt. 기준 화면 390 × 844.
- 테마 값은 앱의 토큰 모듈 한 곳에만 정의하고, 화면은 토큰 이름으로만 참조한다(색 hex를 화면 코드에 직접 쓰지 않는다).

## 1. 원칙

1. **작은 설명 글씨를 두지 않는다.** 화면마다 붙는 안내 문구, 도움말 캡션은 넣지 않는다. 필요한 정보는 제목·값·상태 표시로 전달한다. (예외: 사용자가 판단해야 하는 경고 한 줄. 예: 필수 장소 화면의 "8개 이하여도 배치되지 않을 수 있어요")
2. **지도는 패널을 내려서 본다.** "지도 펼치기" 버튼을 두지 않는다. 결과 화면은 지도 위에 타임라인 패널이 있고, 패널을 아래로 끌면 지도가 드러난다.
3. **상태는 아이콘 + 글자로 표시한다.** 색만으로 구분하지 않는다. 색 태그를 남발하지 않는다.
4. **색은 기본색 하나 + 희망색 하나, 나머지는 무채색.** 주의·오류·완료 색은 그 상태일 때만 쓴다.
5. 굵기는 400과 600 두 단계만 쓴다. 숫자는 고정폭(tabular)이다.

참고한 점: 목록 구성은 금융 앱의 "아이콘 타일 + 굵은 이름 + 회색 설명 + 오른쪽 회색 버튼", 지도는 국내 지도 앱의 "촘촘한 건물, 흰 도로, 노선색, 떠 있는 버튼". 다른 앱의 화면을 그대로 복제하지 않는다.

## 2. 색

| 이름 | 역할 | 값 |
|---|---|---|
| 스카이 블루 | 기본 · 일정 · 선택 · 경로 · 주 버튼 | 경로·버튼 `#2A64A8`, 글자 `#1D4F8A`, 선택 면 `#E5EEF9` |
| 피치 | 희망 장소만 (별 아이콘과 함께) | 글자 `#A8501E`, 지도 표시 `#E2804F`, 면 `#FDEEE4`, 테두리 `#F2D2BE` |
| 앰버 | 주의 · 시간 부족 | 글자 `#8A5A00`, 면 `#FFF4D6` |
| 그린 | 배치 가능 | 글자 `#2F6B12`, 면 `#E3F6D5` |
| 레드 | 오류 · 충돌 · 삭제 | 글자·아이콘 `#D92D20`, 면 `#FEECEB` |
| 그레이 | 본문 · 고정 · 면 | 본문 `#191F28`, 보조 `#4E5968`, 설명 `#6B7684`, 비활성 글자 `#8B95A1`, 선 `#D1D6DB`, 구분선 `#F0F1F3`, 버튼 면 `#F2F4F6`, 비활성 버튼 면 `#E5E8EB` |
| 배경 | 화면 바탕 / 카드 | 바탕 `#F2F4F6`, 카드·시트 `#FFFFFF` |
| 지도 노선색 | 지하철 노선 (75% 투명) | 예: `#E5171F`, `#019A66`, `#E44D93`, `#8A4B22` (도시별 노선 데이터에 따름) |

**구간 순서 색** (지도 경로, 마커 테두리, 목록 번호 타일, 이동 줄 아이콘·세로선이 같은 색을 쓴다. 하늘색 → 보라 → 분홍):

| 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|
| `#5B9BE0` | `#4F86D9` | `#6C7FD6` | `#8A73CC` | `#A367BC` | `#B866A6` |

구간이 6개를 넘으면 이 6색 사이를 보간한다. 텍스트 대비는 4.5:1 이상(24pt 이상은 3:1)을 지킨다.

## 3. 글자

글꼴: **Pretendard** (OFL, 앱에 포함). 자간 -0.01em, 숫자 고정폭.

| 용도 | 크기 / 굵기 |
|---|---|
| 화면 제목 | 20 / 600 |
| 날짜 제목 | 22 / 600 |
| 장소 이름 · 주 버튼 | 17 / 600 |
| 본문 | 16 / 400 |
| 설명 | 15 / 400 |
| 보조 (이동 요약 등) | 14 / 400 |
| 작은 글자 (범례, 개수) | 12–13 / 400 |

굵게(600)는 화면 제목, 날짜 제목, 장소 이름, 선택된 값에만 쓴다.

## 4. 간격 · 모서리 · 크기

- 간격 단계: 4 · 8 · 12 · 16 · 20 · 24 · 32
- 화면 좌우 여백 20 (카드가 있는 목록은 카드 바깥 12, 카드 안쪽 16), 카드 사이 12, 구역 사이 24
- 모서리: 태그·작은 버튼 10, 입력·버튼 14–16, 카드 18–20, 시트·패널 24
- 터치 영역 최소 44 × 44
- 상단 바 높이 56 (뒤로 버튼 44, 제목 20/600)

## 5. 구성 요소

| 요소 | 규칙 |
|---|---|
| 목록 줄 | 왼쪽 40 아이콘 타일(모서리 12, 면 `#F2F4F6`), 이름 17/600, 아래 회색 설명 14, 오른쪽 회색 버튼(높이 36, 면 `#F2F4F6`, 글자 `#4E5968`). 줄 사이 구분선 `#F0F1F3`, 마지막 줄은 없음 |
| 상태 표시 | 아이콘 + 글자. 고정 = 자물쇠 + 회색, 희망 = 별 + 피치, 시간 부족 = 시계 + 앰버, 배치 가능 = 체크 + 그린, 충돌 = 경고 + 레드 |
| 주 버튼 | 높이 56, 모서리 16, 면 `#2A64A8`, 글자 흰색 17/600. 화면 하단 고정 영역(위 12, 아래 28 + 안전 영역) |
| 보조 버튼 | 면 흰색 또는 `#F2F4F6`, 글자 `#4E5968` |
| 비활성 버튼 | 면 `#E5E8EB`, 글자 `#8B95A1` |
| 진행 중 버튼 | 비활성 색 + 원형 스피너 + "다시 확인 중" 같은 진행 문구 |
| 필터 칩 | 높이 34, 모서리 17. 선택 = 면 `#E5EEF9` + 테두리 1.5 `#2A64A8` + 글자 `#1D4F8A` 600 |
| 입력 칸 | 기본 · 입력됨 · 오류 3상태. 포커스 = 안쪽 1.5 테두리 `#2A64A8`. 오류 = 레드 글자와 경고 아이콘, 칸 아래 한 줄 사유(예: "시작일보다 빨라요") |
| 검색 칸 | 높이 52, 모서리 16, 흰 면, 왼쪽 검색 아이콘, 입력 시 지우기 버튼 |
| 스위치 | 50 × 30, 켜짐 `#2A64A8`, 꺼짐 `#D1D6DB` |
| 체크박스(필수 선택) | 원형 26. 선택 = `#2A64A8` 면 + 흰 체크, 해제 = 흰 면 + 2 `#D1D6DB` 테두리. 터치 영역 40 |
| 하단 시트 | 모서리 위 24, 손잡이 36 × 5(`#D1D6DB`), 배경 40% 어둡게. 아래 버튼은 1 : 2 비율(보조 : 주) |
| 이동수단 비교 | 한 줄에 수단 아이콘 + "대중교통 25분 · ¥240", "택시 14분 · 약 ¥2,300". 추정 요금은 "약", 모르는 값은 "—" |
| 토스트 | 아래 떠 있는 흰 카드(모서리 18, 그림자), 아이콘 타일 + 한 줄 + 오른쪽 회색 버튼 |
| 로딩 | 스켈레톤(회색 막대) 1.2초 반복. 동작 줄이기 설정이면 페이드만 |

점선은 지도 위(경로, 희망 마커)에서만 쓴다. 목록·버튼·시트는 실선과 면만 쓴다.

## 6. 지도

**마커**

| 종류 | 표시 |
|---|---|
| 일정(배치된 장소) | 번호 원, 테두리는 해당 구간 순서 색 |
| 숙소 | 집 아이콘 |
| 희망(미배치) | 피치 별 + 이름, 점선 테두리 |
| 선택한 희망 | 피치 면 강조 |

**경로 선**

| 이동 방식 | 선 |
|---|---|
| 대중교통 · 택시 | 실선, 도로를 따라 |
| 도보 | 둥근 점선, 도로를 따라 |
| 도심 밖 이동 | 떠 있는 점선 곡선, 땅에 그림자 |

- 경로는 따로 굵게 덧그리지 않고 **지나는 도로의 색을 바꾸는 느낌**으로 그린다. 선 굵기는 도로 폭에 맞추고 흰 테두리로 도로와 구분한다.
- 두 구간이 같은 도로를 지나면 차선처럼 나눠 그린다.
- 구간마다 중간에 방향 화살표 1개.
- 도로를 따라 그리려면 구간 경로 모양(polyline)이 필요하다(T19). 경로 모양을 받지 못한 구간은 두 지점을 잇는 직선 점선으로 대신한다.
- **도심 밖 판정(기본값):** 도보가 아닌 구간 중 직선거리 4km 이상이거나, 출발·도착지가 도심 범위 밖. 도심 범위는 도시별로 정한다(오사카 예: 순환선 안쪽). 값은 조정 가능하다.
- 공항처럼 화면 밖에 있는 지점은 화면 가장자리에 방향 표시("간사이국제공항 · 화면 밖")를 둔다.
- 지도 범례(이동 · 도보 · 도심 밖 · 희망 N)는 패널 바로 위에 작은 흰 알약으로 띄운다.

## 7. 결과 화면 패널

지도 위에 타임라인 패널이 있고 높이가 세 단계로 걸린다.

| 단계 | 패널 위쪽 위치(844 기준) | 내용 |
|---|---|---|
| 지도 중심 | 약 612 | 요약 줄(여행 이름·기간·일정/희망 개수)만 |
| 기본 | 약 318 | 타임라인이 화면 약 60% |
| 전체 | 상단 바 바로 아래 | 목록 전체 |

- 끄는 영역은 손잡이와 날짜 요약. 그 아래 구분선부터는 일정 목록 스크롤.
- 목록이 맨 위일 때 아래로 끌면 패널이 내려가고, 그 외에는 목록만 스크롤한다.
- 날짜 선택은 지도 위에 떠 있는 버튼이다. 세 단계 모두에서 같은 날짜를 유지한다.

| 동작 | 값 |
|---|---|
| 화면 전환 | 280ms, 오른쪽 24 밀며 페이드, ease-out |

## 9. 화면과 상태

각 화면은 아래 상태를 모두 구현하고 컴포넌트 테스트로 확인한다.

### 1 여행 만들기 (한 화면, 구역 순서대로)
구역: 여행지 · 기간 → 항공편 → 숙소(여러 개, 숙박 기간) → 하루 생활(기본 외출·귀가, 끼니 수, 점심·저녁 시간대, 날짜별 변경) → 이동(택시 정책 사용 안 함 / 필요할 때만 / 선호, 도시 이동 비교: 대중교통·택시·도보의 시간과 요금). 상단에 "확인할 항목 N개", 하단 주 버튼 "장소 추가하기".

| 번호 | 상태 |
|---|---|
| 1-1 | 입력 완료 |
| 1-2 | 입력 전 |
| 1-3 | 누락 · 잘못된 날짜/시각 (예: "귀가 시각이 외출 시각보다 빨라요") |
| 1-4 | 숙소 검색 결과 없음 (지도에서 위치 선택, 주소 직접 입력) |
| 1-5 | 날짜별 예외 수정 (시트: 그날의 외출·귀가, 끼니, 도착 정보, "기본값으로", "저장") |

### 2 장소 추가
상단 바(제목 + 여행지·기간), 검색 칸, 필터 칩(전체 · 명소 · 식당 개수), 장소 목록(상태: 필수 / 희망 · 지도에만 표시, 유형, 체류시간, 고정 조건), 하단 "필수 · 희망" 개수 + 주 버튼 "동선 만들기".

| 번호 | 상태 |
|---|---|
| 2-1 | 목록 |
| 2-2 | 추가한 장소 없음 |
| 2-3 | 검색 중 (스켈레톤) |
| 2-4 | 검색 결과 · 이미 추가한 장소 ("추가됨" 버튼, 토스트 "이미 추가한 장소예요") |
| 2-5 | 검색 결과 없음 ("검색어 지우기") |
| 2-6 | 장소 설정 시트 · 고정 조건 오류 (필수/희망 선택, 체류시간 ±, 날짜·시각·순서 고정 스위치, 오류 사유, 삭제 / 저장) |

### 3 동선 결과
지도 + 패널(7절). 타임라인 줄: 시각, 장소 이름, 날짜·시간·유형, 이동 줄(수단 아이콘 + 시간 + 요금 + "도심 밖"), 숙소 출발/도착, 공항 도착·출발.

| 번호 | 상태 |
|---|---|
| 3-1 | 타임라인 중심 (기본) |
| 3-2 | 지도 중심 (패널 내림) |
| 3-3 | 장소 수정 시트 · 고정/순서 (방문 순서, 희망으로 바꾸기, "적용하고 다시 계산"). 수정 대상 구간만 지도에서 강조 |
| 3-4 | 희망 장소 추가 (추가할 날짜 선택, "N일차에 추가하고 다시 계산") |
| 3-5 | 생성 · 재계산 중 |
| 3-6 | 빈 날짜 ("배치된 장소 없음", 여유 시간, "희망 장소에서 추가") |
| 3-7 | 경로 · 요금 정보 없음 ("요금 —", "택시 정보 없음") |
| 3-8 | 고정 조건 충돌 (원인 두 장소를 지목, "고정된 장소는 자동으로 옮기지 않아요", "○○ 고정 수정", "변경 취소") |
| 3-9 | 계산 실패 ("입력한 장소와 고정 조건은 그대로 있어요", "이전 일정 보기", "다시 계산"). 이전 결과를 보여줄 때는 "이전 계산 결과 · 갱신 실패" 표시 |

### 4 필수 장소 선택 (수용량 초과)
상단 상태 카드(아이콘 타일 + 제목 + 한 줄 설명), 추천 최대 필수 N(추정)과 현재 선택 개수, 후보 목록(원형 체크박스, 해제하면 희망으로 유지), 하단 "여행 조건 수정" + "선택한 N곳으로 다시 계산".

| 번호 | 상태 |
|---|---|
| 4-1 | 선택 전 ("시간이 부족해요") |
| 4-2 | 선택 중 (현재 개수가 N을 넘으면 앰버, 이하면 블루) |
| 4-3 | 고정 해제 확인 시트 (고정된 장소를 희망으로 바꿀 때 풀리는 고정 조건 목록, "필수로 유지" / "고정 해제하고 희망으로") |
| 4-4 | 재검증 중 (목록 흐리게, 버튼 진행 중) |
| 4-5 | 배치 가능 ("동선 보기") |
| 4-6 | 배치 불가 (문제가 된 장소 묶음을 위로, 원인 한 줄, 바로가기 버튼) |

### 그 밖의 화면 (캔버스에 없음)
로그인, 공유, 계정(로그아웃·탈퇴)은 캔버스에 없다. 위 규칙(목록 줄, 버튼, 시트, 색)만으로 구성하고 새 색이나 새 요소를 만들지 않는다.

## 10. 아직 정하지 않은 것

- 글씨체 비교안(Pretendard, 원티드 산스, SUIT 등 9종)이 캔버스에 있으나 현재 적용본은 Pretendard다. 바꾸면 3절만 고친다.
- 색 조합 대안(H1 터콰이즈 + 코랄, H3 코랄 + 민트)이 있으나 현재 적용본은 H2(스카이 + 피치)다. 바꾸면 2절만 고친다.
- 다크 모드는 범위 밖이다.
