# 에이전트 질문과 가정

요구사항이 모호할 때 에이전트가 질문과 채택한 가정을 기록한다. 사람이 답하면 `docs/requirements.md`에 반영하고 여기서는 "답변 완료"로 표시한다.

| 2026-11-18 | T9 | 같은 이동시간 요청의 반복 호출 0회를 Google 응답에도 적용할 수 있는가? | 일반 제공자용 유한 TTL 메모리 캐시와 호출 0회 테스트를 구현한다. 최신 Google Routes 약관에서 시간·거리·요금 보관 허용을 확인하지 못했으므로 Google 기본 팩터리는 완료 응답을 저장하지 않고 진행 중 동일 요청만 합친다. Google 순차 재조회에는 외부 호출이 있으므로 이 부분은 완료 기준 충족으로 주장하지 않는다. 적용 가능한 계약/제공자 또는 완료 기준 해석은 사람 확인이 필요하다. ADR 0005 참조. | 사람 확인 필요 |
