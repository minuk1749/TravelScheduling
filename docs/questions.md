# 에이전트 질문과 가정

요구사항이 모호할 때 에이전트가 질문과 채택한 가정을 기록한다. 사람이 답하면 `docs/requirements.md`에 반영하고 여기서는 "답변 완료"로 표시한다.

| 날짜 | 작업 | 질문 | 채택한 가정 | 상태 |
|---|---|---|---|---|
| 2026-11-18 | T1 | PWA의 오프라인 범위와 DB 도구는? | 오프라인은 요구사항에서 제외되어 서비스워커는 네트워크만 사용한다. DB는 pg 연결 풀만 추가하고 스키마/마이그레이션은 T3에서 정한다. 기존 CI의 PostgreSQL 16과 테스트 스크립트를 사용하며 보호 파일은 수정하지 않는다. | 채택 |
